
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras em Python, praticando manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um jogo da Forca no qual o jogador adivinhe letras para revelar uma palavra oculta antes de esgotar o número de tentativas permitidas.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso atual no formato `_ _ _`.
- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou quando as tentativas se esgotarem.
- Exibir uma mensagem indicando vitória ou derrota.
