# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

Build a small REST API using FastAPI, practicing route creation, request validation, JSON responses, and basic CRUD operations for a simple resource.

## 📝 Tasks

### 🛠️ Create the API Structure

#### Descrição
Set up a FastAPI project that exposes a simple API for managing a collection of items, such as books, tasks, or products.

#### Requisitos
O programa concluído deve:

- Criar uma aplicação FastAPI com um endpoint inicial de teste.
- Definir uma estrutura para armazenar dados em memória.
- Usar modelos de dados para receber e devolver JSON de forma organizada.
- Implementar rotas para listar e criar recursos.
- Exibir respostas em JSON com status HTTP apropriados.

### 🛠️ Implement CRUD Endpoints

#### Descrição
Expand the API to support reading, updating, and deleting items while validating input and handling common error cases.

#### Requisitos
O programa concluído deve:

- Adicionar endpoints para buscar todos os itens, buscar por ID, atualizar e remover itens.
- Usar validação de entrada para garantir que os dados enviados ao servidor estejam corretos.
- Tratar casos como item não encontrado com resposta clara e status HTTP adequado.
- Organizar a API em rotas e modelos legíveis.
- Incluir uma pequena documentação de uso, como descrições de endpoints e exemplos de requisições.
